# 定型ヒアリング定義 1.0

定義の正本は [`schemas/hearing-1.0.json`](../schemas/hearing-1.0.json) です。このファイルはJSON Schemaではなく、画面・検証・レポートで共有する固定データです。完成出力の検証は [JSON Schema 1.3](../schemas/diagnostic-result.schema.json) を使用します。

質問文・ID・選択肢コード・ラベル・条件を勝手に変更せず、意味が変わる改訂はhearing版を分けます。自己申告を自動取得の事実や安全性の判定として扱わず、「その他」は詳細未取得として解釈してください。

旧22問仕様の出力は実装・配布していません。今回の版1.0は20問専用です。もし別のシステムに旧22問データが存在する場合は別版として識別し、旧H-19→新H-18、旧H-21→新H-19、旧H-22→新H-20の対応を文面の一致と共に確認してください。旧H-18／H-20は今回の定義に含まれません。

## 質問一覧

### A. サーバー・ドメイン契約管理（OPS-01）

**H-01** 現在利用しているサーバーの契約・支払いは、主にどなたが管理していますか？

表示条件: 常時。

- `self`: 自社・自身で管理している
- `external`: 制作会社・保守会社などの外部事業者
- `other`: その他
- `unknown`: わからない

**H-02** サイトのドメイン（例：example.com）の契約・更新は、主にどなたが管理していますか？

表示条件: 常時。

- `self`: 自社・自身で管理している
- `external`: 制作会社・保守会社などの外部事業者
- `other`: その他
- `unknown`: わからない

**H-03** サーバーの契約更新や支払い状況を定期的に確認していますか？

表示条件: 常時。

- `yes`: 確認している
- `no`: 確認していない
- `unknown`: わからない

**H-04** ドメインの有効期限や契約更新状況を定期的に確認していますか？

表示条件: 常時。

- `yes`: 確認している
- `no`: 確認していない
- `unknown`: わからない

### B. バックアップ実施・対象（OPS-10）

**H-05** 現在、このWordPressサイトのバックアップを取得していますか？

表示条件: 常時。

- `yes`: 取得している
- `no`: 取得していない
- `unknown`: わからない

**H-06** バックアップには、画像・テーマ・プラグインなどのファイルが含まれていますか？

表示条件: H-05=`yes` の場合のみ。

- `yes`: 含まれている
- `no`: 含まれていない
- `unknown`: わからない

**H-07** バックアップには、投稿・固定ページ・各種設定などが保存されたデータベースが含まれていますか？

表示条件: H-05=`yes` の場合のみ。

- `yes`: 含まれている
- `no`: 含まれていない
- `unknown`: わからない

### C. バックアップ方法・保管先・頻度（OPS-10、OPS-12）

**H-08** バックアップは主にどのような方法で取得していますか？

表示条件: H-05=`yes` の場合のみ。

- `server`: レンタルサーバーなどのバックアップ機能
- `plugin`: WordPressプラグイン
- `manual`: 手動によるバックアップ
- `external_service`: 外部のバックアップサービス
- `multiple`: 複数の方法を併用している
- `other`: その他
- `unknown`: わからない

**H-09** バックアップデータは主にどこに保管していますか？

表示条件: H-05=`yes` の場合のみ。

- `same_server`: Webサイトと同じサーバー内
- `different_location`: 別のサーバーやクラウドストレージ
- `local_device`: パソコンや外付けストレージ
- `multiple`: 複数の場所に保管している
- `other`: その他
- `unknown`: わからない

**H-10** バックアップはどの程度の頻度で取得していますか？

表示条件: H-05=`yes` の場合のみ。

- `daily_or_more`: 毎日、またはそれ以上の頻度
- `weekly`: 週に1回程度
- `monthly`: 月に1回程度
- `less_than_monthly`: 月に1回未満
- `irregular`: 不定期
- `unknown`: わからない

### D. バックアップ取得履歴・復元確認（OPS-14）

**H-11** 最後にバックアップが正常に取得されていることを確認したのはいつですか？

表示条件: H-05=`yes` の場合のみ。

- `within_7_days`: 過去7日以内
- `within_30_days`: 8〜30日前
- `over_30_days`: 31日以上前
- `never`: 一度も確認したことがない
- `unknown`: わからない

**H-12** バックアップデータを使い、実際にWebサイトを復元するテストを実施したことがありますか？

表示条件: H-05=`yes` の場合のみ。

- `within_12_months`: 過去12か月以内に実施した
- `over_12_months`: 12か月より前に実施した
- `never`: 一度も実施していない
- `unknown`: わからない

### E. WordPress更新・保守運用（OPS-18）

**H-13** WordPress本体・テーマ・プラグインの更新作業は、主にどなたが担当していますか？

表示条件: 常時。

- `self`: 自社・自身
- `external`: 制作会社・保守会社などの外部事業者
- `shared`: 自社と外部事業者の両方
- `nobody`: 特に担当者を決めていない
- `unknown`: わからない

**H-14** WordPress本体・テーマ・プラグインに更新があるか、どの程度の頻度で確認していますか？

表示条件: 常時。

- `weekly_or_more`: 週に1回以上
- `monthly`: 月に1回程度
- `less_than_monthly`: 月に1回未満
- `irregular`: 不定期
- `never`: 確認していない
- `unknown`: わからない

**H-15** WordPressの更新作業を行う前に、バックアップが取得できているか確認していますか？

表示条件: 常時。

- `always`: 毎回確認している
- `sometimes`: 場合によって確認している
- `never`: 確認していない
- `no_updates`: 更新作業を実施していない
- `unknown`: わからない

**H-16** WordPressの更新作業を行った後、サイトの表示やお問い合わせフォームなどが正常に動作しているか確認していますか？

表示条件: 常時。

- `always`: 毎回確認している
- `sometimes`: 場合によって確認している
- `never`: 確認していない
- `no_updates`: 更新作業を実施していない
- `unknown`: わからない

### F. 障害対応・監視体制（OPS-19）

**H-17** サイトが表示されない、正常に動作しないなどの問題が発生した際に、対応する担当者や相談先は決まっていますか？

表示条件: 常時。

- `internal`: 自社内に担当者がいる
- `external`: 外部の制作会社・保守会社などに相談できる
- `both`: 自社と外部事業者の両方で対応する
- `none`: 特に決まっていない
- `unknown`: わからない

**H-18** サイトが正常に稼働しているか、定期的に確認していますか？

表示条件: 常時。

- `automated`: 監視サービスなどで自動確認している
- `manual`: 担当者が手動で定期的に確認している
- `both`: 自動・手動の両方で確認している
- `none`: 定期的な確認はしていない
- `unknown`: わからない

### G. 管理者アカウント・ログイン保護（WP-11、WP-12の補助）

**H-19** WordPressの管理者権限を持つアカウントについて、誰が何のために利用しているか把握していますか？

表示条件: 常時。

- `all`: すべて把握している
- `some`: 一部のみ把握している
- `none`: 把握していない
- `unknown`: わからない

**H-20** WordPress管理画面へのログインで、二要素認証（パスワードに加え、認証アプリなどで本人確認する仕組み）を利用していますか？

表示条件: 常時。

- `all_admins`: すべての管理者が利用している
- `some_admins`: 一部の管理者が利用している
- `none`: 利用していない
- `unknown`: わからない
