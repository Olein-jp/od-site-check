WordPressサイトの構成・運用環境を確認し、診断用JSONを生成します。

== Description ==

OD Site Checkは、オレインデザインによるWordPress運用・改善診断のための情報収集プラグインです。

管理画面の「ツール > OD サイト診断」から、WordPress本体、テーマ、プラグイン、設定、PHP、データベースなどの情報を収集できます。項目別の取得状況と、ヒアリング前に確認していただきたい契約・運用情報を表示します。固定20問の定型ヒアリングに回答すると、診断結果と自己申告をまとめたJSONをコピー・ダウンロードできます。H-05が「取得している」の場合は20問、それ以外は13問に明示的な回答が必要です。回答は保存されず、再読込・離脱・再診断で破棄されます。

サイト設定の変更、更新、修復、バックアップ、診断結果の外部送信は行いません。パスワード、APIキー、認証情報、ユーザーの氏名・メールアドレスは収集しません。ユーザー一覧の閲覧権限がある場合は、ログイン名と権限グループを収集します。

== Installation ==

1. WordPress管理画面から配布ZIPをアップロードします。
2. OD Site Checkを有効化します。
3. 「ツール > OD サイト診断」を開きます。
4. 診断後に定型ヒアリングへ回答し、JSONをコピーまたはダウンロードします。
5. 調査完了後にプラグインを無効化・削除します。

== Frequently Asked Questions ==

= 診断結果は自動送信されますか？ =

外部へ自動送信されません。明示的にコピー・ダウンロードを押した時だけ、同じサイト内のサーバーで診断の署名・権限・回答を検証し、保存せずに出力します。管理者がJSONを手動でオレインデザインへ提出します。

= サイトの設定やデータは変更されますか？ =

変更されません。初期版の診断処理は読み取り専用です。

= マルチサイトに対応していますか？ =

初期版では対応していません。マルチサイトを検出した場合は、対象項目を未対応として記録します。
